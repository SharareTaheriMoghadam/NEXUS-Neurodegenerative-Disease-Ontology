# NEXUS Ontology

This directory contains a selected public-facing representation of the NEXUS ontology.

## Authoritative ontology

The complete NEXUS ontology is available through BioPortal:

https://bioportal.bioontology.org/ontologies/NEXUS

The BioPortal release should be considered the authoritative ontology distribution.

## Public subset

The file:

`nexus_public_subset.ttl`

contains selected ontology classes, relationships, annotations, and representative OWL restrictions derived from NEXUS v1.0.

The subset is intentionally non-exhaustive.

It is provided to:

- demonstrate the semantic architecture of NEXUS;
- illustrate major ontology classes;
- demonstrate representative relationships;
- support reproducible examples;
- provide a research-facing technical representation;
- support the competency questions and SPARQL examples in this repository.

It is not intended to replace the complete ontology release.
